# Готовность Android-проекта к релизу

Проверено **14 сентября 2026 года** на коммите `052f518`.

Статусы относятся к репозиторию. Действия в Play Console и вопросы прав на
контент вынесены в
[`news_sources_licensing_and_google_play.md`](news_sources_licensing_and_google_play.md).

## Осталось до первого релиза

- [ ] **Подписать release-сборку.** Готово, когда signing config читает upload
  key и пароли вне Git, `*.jks`/`*.keystore` добавлены в `.gitignore`, а
  `jarsigner -verify app-release.aab` подтверждает подпись.
- [ ] **Опубликовать страницу контактов и Privacy Policy.** Готово, когда
  `https://yansubaev.github.io/News-Observer/` и используемые якоря отвечают без
  ошибки и совпадают со ссылками в приложении и Play Console. Сейчас URL
  возвращает `404`.
- [ ] **Решить доступность исходного кода.** Готово, когда репозиторий доступен
  без авторизации либо ссылка на него удалена из приложения и публичной
  страницы. Сейчас публичный URL возвращает `404`.
- [ ] **Зафиксировать baseline Room.** Готово, когда включён `exportSchema`,
  схема версии 14 сохранена в репозитории, destructive fallback удалён, а для
  следующих изменений действует правило «новая версия + `Migration` + тест».
- [ ] **Проверить подписанный release на физическом устройстве.** Готово, когда
  пройден smoke-check из раздела ниже на той же сборке, которая загружается в
  Play.

## Завершено

- [x] **Изоляция News API и изображений.** News API и его ключ отсутствуют в
  release; `IMAGES_ENABLED = false`; это закреплено `ReleaseIsolationTest`.
- [x] **Безопасное сетевое поведение.** В release логирование имеет
  `Level.NONE`, cleartext-трафик запрещён.
- [x] **Экран «О приложении и источники».** Показаны разработчик,
  независимость, источники, условия, контакты и юридические ссылки.
- [x] **Жалоба на материал.** Экран статьи создаёт письмо с URL, издателем и
  заголовком.
- [x] **Атрибуция и короткий сниппет.** Издатель виден в уведомлении, описание
  сокращается на экране статьи и в уведомлении.
- [x] **Очистка кэша.** Неиспользуемые ленты и их неизбранные статьи удаляются
  после 30 дней; избранное сохраняется.
- [x] **Резервное копирование отключено.** Room и DataStore исключены из cloud
  backup и переноса между устройствами.
- [x] **R8 и shrink resources.** Минификация включена, DTO защищены правилами,
  `mapping.txt` создаётся.
- [x] **Release-сборка и unit-тесты.** `testDebugUnitTest`,
  `testReleaseUnitTest` и `bundleRelease` проходят.
- [x] **Target SDK.** Проект использует `targetSdk 37`, что не ниже актуального
  требования Google Play — API 36.

## Перед каждой загрузкой

- [ ] Увеличен `versionCode`; `versionName` соответствует релизу.
- [ ] `testDebugUnitTest`, `testReleaseUnitTest` и `bundleRelease` проходят.
- [ ] AAB подписан; сохранены upload key и резервная копия.
- [ ] На release-сборке работают лента NewsData.io и GDELT, поиск, избранное,
  очистка кэша, уведомление и открытие оригинала.
- [ ] На каждой статье видны издатель и дата; News API и изображения отсутствуют.
- [ ] Все ссылки и создание письма работают на устройстве.
- [ ] `mapping.txt` сохранён для загрузки вместе с AAB.
- [ ] Скриншоты Store Listing сняты с проверенной release-сборки.

## Опционально

- [ ] **Экран open-source лицензий.** Нужен только если принято продуктовое
  решение показывать лицензии внутри приложения; до этого достаточно лицензий
  в публичном репозитории.
